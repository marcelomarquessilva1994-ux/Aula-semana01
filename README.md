# Fundamentos de Git e GitHub

> Primeiros passos na construção de um portfólio acadêmico e profissional em Ciência da Computação.

## 📚 Sobre o projeto

Este repositório registra uma das primeiras atividades práticas da minha graduação em **Ciência da Computação**.

O projeto tem como objetivo compreender os fundamentos do **Git e GitHub**, explorando a criação de repositórios, versionamento, commits, organização de arquivos e documentação de projetos.

Mais do que uma atividade inicial, este repositório representa o início da construção do meu portfólio técnico ao longo da graduação.

## 🎯 Objetivos

- Compreender os fundamentos do Git e GitHub;
- Criar e organizar um repositório;
- Trabalhar com commits e versionamento;
- Utilizar arquivos Markdown para documentação;
- Desenvolver boas práticas de organização de projetos;
- Iniciar a construção de um portfólio acadêmico e profissional.

## 🛠️ Tecnologias e ferramentas

- Git
- GitHub
- Markdown
