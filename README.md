# 🚀 Aula Semana 01 — Introdução ao GitHub

> Primeiro projeto desenvolvido durante minha jornada acadêmica em Ciência da Computação.

## 👨‍💻 Sobre o projeto

Este repositório faz parte das atividades iniciais do curso de **Ciência da Computação** e tem como objetivo registrar meu primeiro contato acadêmico com o GitHub e com práticas de versionamento de código.

A proposta desta atividade é compreender os fundamentos da utilização do GitHub como ferramenta de desenvolvimento, documentação e construção de portfólio profissional.

---

## 🎯 Objetivos

- Compreender a estrutura básica de um repositório GitHub;
- Aprender os conceitos iniciais de Git e GitHub;
- Criar e organizar um repositório;
- Trabalhar com arquivos README e documentação;
- Registrar minha evolução acadêmica por meio de projetos;
- Desenvolver boas práticas desde o início da formação.
